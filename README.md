# File Highlighter

Automatically highlights imported folders and files while providing native folder coloring and styling in the Unity Project window.

---

## What It Does

File Highlighter combines real-time import tracking with customizable folder styling. Whenever you import packages, extract zip archives, or move assets, it highlights affected files with smooth fade-out timers so you never lose track of new assets. It also includes Folder Color Studio to organize your project window with custom colors, accent bars, and emoji badges.

### Key Features

* **Import & Delete Tracking:** Highlights newly added and deleted files in the Project window with configurable duration and colors.
* **Folder Color Studio:** Right-click any folder to apply signature palette colors, custom hex tones, or reset styling.
* **Visual Hierarchy Overlay:** Shows parent folder tree paths so nested assets are easy to locate immediately.
* **Accent Stripes & Badges:** Style folders with side stripes, background tints, and tag badges like FOX, VRC, TEX, or custom text.
* **Subfolder Inheritance:** Control whether child folders inherit parent styling automatically.
* **Ping & Explorer Navigation:** Quickly locate assets in the Unity Project window or open their folders in Windows Explorer.
